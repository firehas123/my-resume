# Project: personal resume and portfolio site

Muhammad Hassan Chattha's resume/portfolio, deployed on Vercel from this repo.
Next.js (App Router) + TypeScript, CSS Modules + CSS variables, Motion for
animation, React Three Fiber for a single lazy 3D element in the hero.

The owner knows Java and is new to JavaScript: keep code readable and add short
comments where something is not obvious.

## Rules

- **Never invent facts** about the owner. Missing information is a visible `TODO`
  in the data (rendered highlighted via `TodoText`) and listed in `REVIEW.md`.
- **Never show the phone number or email address** on the site. The contact form
  (`/contact`) is the way to reach him.
- **Private GitHub repos must never appear.** `scripts/sync-projects.mjs` keeps only
  `isPrivate === false && isFork === false`.
- `src/data/projects.json` is generated by `npm run sync`. Never edit it by hand;
  manual changes go in `src/data/overrides.json` (overrides always win).
- The site must build on Vercel with default settings, and the host must not need `gh`.
- Do not draw, generate or download company logos. They are optional files in
  `public/logos/` with a text fallback.
- Use the MHC logo artwork exactly as in `src/components/ui/Logo.tsx`; do not redraw it.
- `design-reference/` holds the static design pictures (dark and light). It is not
  part of the built site, but the layout, spacing, type sizes, colours and section
  order should keep matching it.

## Design system

- All colours are CSS variables in `src/app/globals.css`, defined once per theme
  (`:root[data-theme="dark"|"light"]`). Components never use raw hex values.
  - `.band-dark` (About, Get in touch, footer) stays black in both themes.
  - `.band-light` (Experience) is light in both themes.
  - Each accent (`--accent-bright`, `--accent-deep`) is a one-line change.
- One font: Manrope 400–800 via `next/font/google`.
- 28px card radius, pill buttons, 1px hairlines, 8px spacing grid, single-stroke icons.
- Restraint: no decorative gradients, glows or heavy shadows, no emoji, no stock icons.
- Text contrast must pass WCAG AA (4.5:1) in both themes, on every band.
- Touch targets at least 44px; visible keyboard focus; labelled form fields.

## Motion

- Soft ease-out curves, 300–700ms; only the cursor effect may settle springily.
- With `prefers-reduced-motion`: no intro, no 3D, no sliding, no drifting, no reveals.
- The theme and the intro flag are set by an inline pre-paint script
  (`src/lib/theme.ts`) to avoid a flash. The intro is pure CSS (~1.4s, once per
  session via sessionStorage) and the real page always renders underneath.
- `usePushField` (cursor push) uses requestAnimationFrame and transforms only, and
  pauses off screen.

## Structure

- `src/data/profile.json`: all personal content. Typed in `src/lib/profile.ts`.
- `src/lib/projects.ts`: merges projects.json + overrides.json + content/projects/*.md.
- `src/components/sections/`: one component per home-page section, in page order
  in `src/app/page.tsx`.
- Server components by default; `"use client"` only where state, effects or browser
  APIs are needed.
